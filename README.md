# WalkLearn — نسخة Python/Kivy للهاتف

هذه نسخة شخصية من مشروع **WalkLearn** الأصلي، تم تحويلها من Next.js/React إلى Python + Kivy.

## لماذا التحويل؟

المشكلة التي ظهرت عندك ليست من المشروع نفسه فقط؛ `npm install` توقف بسبب `ETIMEDOUT`، كما أن `node_modules` لم يُنشأ، لذلك `next` صار غير موجود.

النسخة الجديدة:
- لا تحتاج Node.js أو npm.
- لا تحتاج Next.js.
- لا تحتاج قاعدة بيانات أو سيرفر.
- كل المحتوى داخل `curriculum.json`.
- التقدم محفوظ محليًا داخل بيانات التطبيق.
- تعمل دون إنترنت بعد تثبيت التطبيق.
- النطق يستخدم Android Text-to-Speech.
- أضفت XP وسلسلة الأيام.
- محتوى الدروس الـ12 في النسخة الأصلية محفوظ كما هو.

## محتويات النسخة

- اختبار تحديد المستوى A1 → C1.
- 12 درسًا.
- مفردات + أمثلة.
- حفظ ومراجعة الكلمات.
- تمرين كتابة.
- قواعد.
- قراءة واستماع في B2/C1.
- اختبار قصير.
- حفظ التقدم.
- XP وسلسلة الأيام.
- واجهة عربية.
- APK مستقل بدل تشغيل الموقع في Termux.

## أهم تطويرات مقترحة لاحقًا

1. نظام مراجعة ذكي للكلمات التي أخطأت فيها.
2. خطة يومية تلقائية: 10–15 دقيقة.
3. صفحة إحصائيات أكثر تفصيلًا.
4. اختبار مستوى جديد قابل للتغيير بدل الأسئلة الثابتة.
5. تصدير/استيراد نسخة احتياطية للتقدم.
6. إضافة دروس أكثر لكل مستوى.
7. تسجيل نطق المستخدم ومقارنته بالنطق النموذجي — هذه مرحلة لاحقة لأنها تحتاج مكونات صوتية أكبر.

## تشغيل APK بدون Termux

المشروع مجهز بملف `buildozer.spec` وGitHub Actions.

أسهل طريقة من الهاتف:
1. أنشئ مستودع GitHub جديد باسم `walklearn`.
2. ارفع كل ملفات هذا المجلد.
3. افتح تبويب **Actions**.
4. شغّل `Build WalkLearn APK`.
5. بعد انتهاء البناء، ستجد ملف APK داخل **Artifacts** باسم `WalkLearn-APK`.
6. نزّل APK وثبّته على هاتفك.

## تشغيل محلي للتجربة

إذا أردت تجربة Python قبل بناء APK، تحتاج بيئة Python فيها Kivy:

```bash
pip install -r requirements.txt
python main.py
```

على أندرويد، الهدف النهائي هنا هو **APK مستقل**، وليس تشغيل البرنامج من Termux.
